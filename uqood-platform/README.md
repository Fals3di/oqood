# نظام «عُقود» الذكي لإدارة وأرشفة العقود والأصول
## Smart Contract & Asset Management Platform

منصة سحابية (SaaS) شاملة لإدارة جميع أنواع العقود والاتفاقات التعاقدية مع إدارة الأصول والمصاريف المرتبطة بها.

## 📋 نظرة عامة

«عُقود» هو نظام متكامل مصمم للشركات الصغيرة والمتوسطة، والأفراد، والشركاء الذين يديرون محافظ تعاقدية متنوعة. النظام يركز على **العقد** ككيان مركزي، مع دعم كامل للأصول الاختيارية المرتبطة به.

### المميزات الرئيسية

- ✅ **إدارة العقود الشاملة**: جميع أنواع العقود التجارية والفرعية
- ✅ **الملاحق العقدية**: تعديل العقود النشطة دون المساس بالأصل
- ✅ **إدارة الأصول**: عقارات، مركبات، معدات، تراخيص، أصول غير ملموسة
- ✅ **نظام مالي متكامل**: دفعات، مصاريف، شيكات، دفتر حركات (Ledger)
- ✅ **نظام اعتمادات مرن**: Maker-Checker بسياسات قابلة للتخصيص
- ✅ **الذكاء الاصطناعي**: OCR، استخراج البيانات، تقييم المخاطر
- ✅ **التعاون**: محادثات، مهام، شركاء بصلاحيات متدرجة
- ✅ **Webhooks وAPI**: تكامل لحظي مع أنظمة ERP والمحاسبة

## 📊 نموذج البيانات

النظام يستخدم PostgreSQL مع JSONB للحقول الديناميكية، مما يوفر:

- **مرونة كاملة**: إضافة حقول مخصصة دون تعديل البنية
- **أداء عالي**: فهارس GIN للبحث السريع في JSONB
- **قابلية التوسع**: دعم حتى 100,000 مستخدم

### الكيانات الرئيسية

- **Organization**: المؤسسة (Multi-tenant)
- **User**: المستخدمون بأدوار مختلفة
- **Partnership**: الشركاء ونسب الأرباح
- **Portfolio**: محافظ تجميع العقود والأصول
- **Asset**: الأصول (اختياري - عقارات، مركبات، معدات...)
- **Contract**: العقود (الكيان المركزي)
- **ContractAddendum**: الملاحق العقدية
- **ContractClause**: بنود العقد الديناميكية
- **PaymentSchedule**: جدول الدفعات
- **Expense**: المصاريف الفعلية
- **Cheque**: إدارة الشيكات
- **LedgerEntry**: دفتر الحركات المالية (Append-Only)
- **ApprovalRequest/Policy**: نظام الاعتمادات
- **WebhookSubscription**: تكاملات Webhooks
- **AuditLog**: سجل التدقيق غير القابل للتعديل

## 🔄 دورة حياة العقد

```
مسودة ← بانتظار الاعتماد ← نشط ← منتهٍ أو مُجدد
                ↓
            تنبيهات 90/60/30 يوماً قبل الانتهاء
```

### الملاحق العقدية

- أي تعديل على عقد نشط يُسجل كملحق مرقّم (Addendum 1, 2, ...)
- العقد الأصلي لا يُعدّل أبداً
- النسخة الفعالة = الأصل + الملاحق المعتمدة
- إعادة جدولة الدفعات من تاريخ سريان الملحق فقط

## 💰 النظام المالي

### دفتر الحركات (Ledger)

- **Append-Only**: كل حركة تُضاف ولا تُحذف
- **التصحيح**: بقيد عكسي (Reversal Entry) مرتبط بالقيد الأصلي
- **مسار للقيد المزدوج**: قابل للترقية مستقبلاً لـ Enterprise

### الأحداث المالية المُسجّلة

- الدفعات المستحقة والمدفوعة
- المصاريف الفعلية
- الشيكات (إصدار، إيداع، صرف)
- توزيعات الأرباح
- تعديلات الملاحق العقدية

## 🤖 الذكاء الاصطناعي

### Contract Intelligence

1. رفع ملف العقد (PDF/صورة)
2. OCR لاستخراج النص
3. تحليل ذكي يستخرج:
   - التواريخ والقيمة والأطراف
   - شروط الدفع والتجديد
   - الغرامات والمخاطر القانونية
4. عرض النتائج للمراجعة قبل الحفظ

### Risk Scoring

درجة مخاطرة (0-100) على أربعة محاور:
- **مالي**: القيمة، الالتزام بالدفعات
- **زمني**: مدة العقد، التجديد
- **قانوني**: البنود الحساسة
- **سمعة**: تقييم الطرف الآخر

- سجل تسليم شامل

## 🛡️ الأمان والخصوصية

- **JWT** عبر httpOnly Cookies
- **RBAC** على مستوى الخادم
- **Zod Validation** لكل المدخلات
- **Rate Limiting** لمنع الإساءة

- **عزل Multi-tenant** كامل
- **سجل تدقيق** غير قابل للتعديل

## 📱 العمل دون اتصال

تطبيق الجوال يدعم Offline-First:
- عرض البيانات المخزنة محلياً
- إضافة الفواتير والمستندات دون إنترنت
- مزامنة تلقائية عند الاتصال
- حل تضارب ذكي
